# Changelog

## 0.1.0 — unreleased

* Manuscript-derived reference implementation of MARS-TB (ViT-B/16 + LoRA, MS-VLE, DDFM, AGRN, PRM, MT-EDL).
* Data tooling: preprocessing, manifests with JSON schemas, reproducible split generator and verifier,
  two-hash near-duplicate leakage audit.
* Training, checksummed checkpoints, evaluation (DeLong, patient-clustered bootstrap, Holm, calibration,
  uncertainty), explainability, efficiency benchmark, baselines and ablations.
* Reporting: CLAIM 2024 and TRIPOD+AI checklists, artifact inventory, manuscript consistency audit, parameter
  accounting, known-discrepancy register.
* **Not included:** trained weights, exact historical split files, prediction files, original code, a licence.
